# 02 Windows-DNS-Server

Übung **02.1**: DNS-Rolle installieren, Lauschadressen, Root Hints, Ereignisprotokoll, Rekursion aus- und wieder einschalten. Geschätzte Zeit: 6 Stunden (Lehrplan: 8 UE).

> Nicht auf Windows ausgeführt, Cmdlets nur gegen Microsoft Learn geprüft (siehe Warnhinweis in der Übung).

| Datei | Zweck |
|---|---|
| `02.1-windows-dns-server-einrichten.md` | Die Übung |
| `02.1-dns-rolle-installieren.ps1` | Installiert die Rolle samt Verwaltungstools |
| `02.1-lauschadressen-setzen.ps1` | Setzt die Lauschadressen des DNS-Servers |
| `02.1-einstellungen-sichern.ps1` | Sichert die Server-Einstellungen vor Experimenten |
